# abdullahalrafi.github.io

Personal research portfolio of Abdullah Al Rafi.

## Structure
```
index.html                      page shell + SEO tags
google531bd3cb6daf6be1.html     Google Search Console verification (keep at root)
404.html  robots.txt  sitemap.xml  .nojekyll
assets/
  css/style.css                 design + dark mode + print styles
  js/data.js                    ALL content lives here (edit this file)
  js/script.js                  renders the page from data.js
  img/profile.jpg  favicon.svg
  docs/                         put cv.pdf here, then set cv:"assets/docs/cv.pdf" in data.js
```

## Deploy
Repo name must be `abdullahalrafi.github.io`. Push to `main`, then Settings → Pages → Deploy from branch → `main` / root.
